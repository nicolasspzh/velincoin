Velincoin Core
==============

Intro
-----
Velincoin (VLC) is an open source peer-to-peer cryptocurrency with its own
blockchain. It is a fork of Bitcoin Core. Users hold the keys to their own
coins and transact directly with each other, with the help of a P2P network
to check for double-spending.

Velincoin is in development. The main network has not been launched publicly
yet. Use the Velincoin test network ("Velincoin Core (testnet)" in the start
menu) to try it out.


Setup
-----
Run velincoin-qt.exe (or use the start menu entry).

Every Windows user gets their own data directory and wallets in
%LOCALAPPDATA%\Velincoin. Inside the program you can create several wallets
with File > Create Wallet.

Keep backups of your wallet (File > Backup Wallet) and never share the
wallet files: whoever has them has the coins.
