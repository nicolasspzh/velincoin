About

Velincoin is a digital currency with its own blockchain. No company issues it and no bank holds it. New coins only come from mining, and every computer on the network checks every payment against the same public rules.

21,000,000VLC

That is the most there will ever be. The limit is part of the protocol, and every node on the network enforces it.

01

Fixed supply

No one can create extra coins, not even the people who write the software. A block that tries to is rejected.

02

No premine

Every coin is mined. Nobody received coins in advance, and nothing was sold before launch.

03

Open source

The software is published under the MIT licence. Anyone can read it, check it and run it.

04

Your keys

The wallet keeps your keys on your own device. There is no account to open and no one to ask for permission.

How it works

From a mined block to your wallet.

Three parts keep Velincoin running. None of them needs a bank, a company or a central server.

Mining

Miners collect new payments into a block and compete to solve a hard computing puzzle. The winner adds the block to the chain and is paid in newly created VLC.

Verification

Every node keeps its own copy of the chain and checks each new block. A block that breaks a rule is thrown out, no matter who sent it.

Ownership

Coins belong to whoever holds the private key. You sign payments on your own device, and the key never leaves it.

Wallet

Your coins and your own node, in one app.

Velincoin Core is the official wallet. It does not ask a server what your balance is. It downloads the chain and checks it itself, so what you see is what the network agreed on.

Get started

Try it on the test network.

The main network has not launched yet. You can already build the software and use it on the test network, where coins have no value. The commands below are for Linux.

  1. Build the software

    In the Velincoin Core source folder:

    sudo apt-get install build-essential cmake pkgconf \
  python3 libevent-dev libboost-dev libsqlite3-dev
cmake -B build -DBUILD_GUI=OFF -DWITH_ZMQ=OFF -DENABLE_IPC=OFF
cmake --build build -j4

  2. Start a node

    The node runs in the background. Add another node on the test network so yours can find it.

    build/bin/velincoind -testnet4 -daemon
build/bin/velincoin-cli -testnet4 addnode "<peer-ip>:29733" "add"

  3. Create a wallet

    Make a wallet and get your first address. Test network addresses start with tvlc1.

    build/bin/velincoin-cli -testnet4 createwallet "my-wallet"
build/bin/velincoin-cli -testnet4 getnewaddress

FAQ

Questions, answered plainly.

Can I buy Velincoin?

Not yet. Velincoin has not launched, and there is no exchange, no token sale and no presale. If someone offers to sell you VLC today, it is not Velincoin.

How do new coins come into existence?

Only through mining. Whoever adds a valid block to the chain receives newly created VLC, until the limit of 21 million is reached.

Who controls Velincoin?

No one in particular. The rules live in open source software, and every node checks them for itself. A change only takes effect if the people running nodes choose to install it.

Is it safe to use right now?

Not for anything of value. A young proof-of-work network is small, and someone with a lot of rented computing power could overpower it. Until the network has grown and the mining algorithm is final, use it for testing only.

What do I need to run a node?

A computer with Linux, a few minutes to build the software, and an internet connection. To accept connections from others, open TCP port 29733 on the test network.
