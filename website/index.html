Run a node

A node downloads the chain, checks every block against the rules and talks to other nodes. Velincoin Core is the reference node and wallet. These commands are for Linux.

  1. Build from source

    In the Velincoin Core source folder:

    sudo apt-get install build-essential cmake pkgconf \
  python3 libevent-dev libboost-dev libsqlite3-dev
cmake -B build -DBUILD_GUI=OFF -DWITH_ZMQ=OFF -DENABLE_IPC=OFF
cmake --build build -j4

    The programs end up in build/bin/. For the desktop wallet, install the Qt 6 packages and configure with -DBUILD_GUI=ON.

  2. Practise on your own machine

    Regtest is a private chain where blocks appear instantly. Mine 101 blocks, because a block reward can only be spent after 100 more blocks.

    build/bin/velincoind -regtest -daemon
build/bin/velincoin-cli -regtest createwallet "demo"
build/bin/velincoin-cli -regtest getnewaddress
build/bin/velincoin-cli -regtest generatetoaddress 101 <address>
build/bin/velincoin-cli -regtest getbalance   # 50.00000000

  3. Join the test network

    The testnet is a real network with no value. There are no seed servers yet, so you add peers by hand. Open TCP port 29733 to accept connections.

    build/bin/velincoind -testnet4 -daemon
build/bin/velincoin-cli -testnet4 addnode "<peer-ip>:29733" "add"
build/bin/velincoin-cli -testnet4 getconnectioncount

    The built-in miner uses one CPU core. On the testnet that means roughly 15 to 25 minutes per block, depending on the machine and on luck.

What is different

The network. Velincoin has its own genesis block, its own network magic and its own ports and address formats. Velincoin nodes and Bitcoin nodes do not recognise each other and never exchange data.

Code

Velincoin Core is a fork of Bitcoin Core 31.1, released under the MIT licence. The difference to upstream is kept small on purpose, so that future Bitcoin Core fixes can be carried over.

Network

Two public networks: the main network, which has not started yet, and a test network for trying things without value.

Finding peers

No seed nodes are configured yet. Until they are, a node only finds the network if you tell it where to look, for example with -addnode=<ip>:9733.

Testnet rules

Like Bitcoin’s testnet4: if no block is found for 20 minutes, the next block may be mined at minimum difficulty. That keeps the testnet usable with ordinary computers.

Security

Velincoin uses SHA-256, the same proof of work as Bitcoin. For a small new chain that is a real weakness, and we would rather say so up front.

The risk

Almost all SHA-256 mining hardware in the world works on Bitcoin. Anyone who rents a small slice of it for a few hours could out-mine the whole Velincoin network. With that majority they could reverse their own payments and push other miners’ blocks off the chain. They could not take coins from other people or create coins outside the rules.

Our position

Keep SHA-256 while Velincoin has no market value and runs as a test network. Decide again before any public launch. The two serious options are merged mining with Bitcoin, which is the strongest if pools take part, or RandomX, which lets anyone mine with an ordinary CPU.

Any switch should happen before launch. Until then the chain can simply be restarted. After launch the same change is a hard fork that every node and miner has to make at once.

Until then: treat confirmations on Velincoin as weak, and do not accept VLC for anything of value.
